# Club-supplied logos

The eight archive files are original images from the club's `LOGOS.rar`, copied
without alteration. `legrena.jpg` is the original `1-Photo-1.jpg` attached
separately by the club. The active SHADOWS crest, `shadows-fc-black-pink.jpg`,
is the later 1254×1254 black/pink attachment, also copied without alteration.
The original white-background `shadows-fc.jpg` is retained as an archive asset.
The active crest appears in the header, footer, match cards, details and browser
icon. Legrena, Aston Voula, Unathletico and Savralliolid
are matched to their existing results. CSS frames Legrena's portrait canvas
without its empty top/bottom margins; the source JPEG remains unaltered.
