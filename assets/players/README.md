# Player portraits

Original club-supplied JPEG files from `SHD.rar`, copied without alteration.
The filename is the confirmed shirt number and `data.js` maps it to the player.

The club confirmed `10.jpeg` is Tasos Babakos (#10, striker). All 12 supplied
portraits are assigned. The photo for Gkoumas Konstantinos (#6) is still
missing. No replacement likeness or guessed player identity is used.
