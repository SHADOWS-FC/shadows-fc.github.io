# Player portraits

Original club-supplied JPEG files from `SHD.rar`, copied without alteration.
The filename is the confirmed shirt number and `data.js` maps it to the player.

The club confirmed `10.jpeg` is Tasos Babakos (#10, striker), and supplied
`6.jpeg` for Gkoumas Konstantinos in the updated archive. All 13 original
portraits are assigned. No replacement likeness or guessed identity is used.
